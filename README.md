# Neil Tripathi

I build things at the intersection of ML research and systems engineering. Right now I'm focused on runtime safety for robot learning policies, temporal reasoning in language models, and biologically-inspired locomotion from real connectome data.

**[neiltripathi.com](https://website-phi-tan-29.vercel.app)**

## Current work

- **[TAP-Score](https://github.com/neilt93/TAP-Score)** — runtime failure detection for Diffusion Policy; predicts when visuomotor policies will fail so the robot can abstain from risky actions (Can AUROC 0.972, Lift obs-only 0.982)
- **[temporal-bench](https://github.com/neilt93/temporal-bench)** — benchmark for temporal reasoning in LLMs, testing whether models recognise when their context is stale (finding: more capable models are more confidently wrong)
- **[Visual-Benchmark](https://github.com/neilt93/Visual-Benchmark)** — evaluating whether vision-language models can determine what is and is not visible in a photograph (9 models, arXiv submitted)

## Other projects

- **[NeilGPT](https://github.com/neilt93/NeilGPT)** — 24M-parameter transformer trained from scratch on personal chat data with custom BPE tokenisation
- **[NFL-Coaching-Sim](https://github.com/neilt93/NFL-Coaching-Sim)** — interactive coaching simulator with 3D field visualisation in Three.js
- **[Digital-persona](https://github.com/neilt93/Digital-persona)** — local-first AI agent that mirrors your conversational style, grounded in your own documents
- **[mcp-debug](https://github.com/neilt93/mcp-debug)** — testing toolkit for Model Context Protocol servers with trace recording, diffing, and stress testing
